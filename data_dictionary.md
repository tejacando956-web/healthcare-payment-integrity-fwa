# Data Dictionary — Payment Integrity Analytics (FWA Detection)

Synthetic data only — generated by `generate_data.py` (seed 42). No PHI, no real patients/providers.

## data/claims.csv (~2,767 rows, one row per claim line)
| Column | Type | Description |
|---|---|---|
| claim_id | string | Unique claim ID, `CLM000001` style, assigned in claim-date order |
| patient_id | string | Synthetic member ID (`P0001`–`P1200`) |
| provider_id | string | Rendering provider, joins to providers.csv |
| procedure_code | string | CPT-style procedure code (read as string — codes are numeric-looking) |
| units | int | Units billed. Therapy codes (97110/97530) are per-unit: 1–4 typical, ≥6 = excessive |
| billed_amount | float USD | Charged amount (per-unit price × units for therapy codes) |
| paid_amount | float USD | Amount paid; 0.00 when status = Denied. Paid ratio ≈ 55–85% of billed on paid claims |
| claim_date | date | Service/claim date in 2025 |
| status | string | `Paid` or `Denied` |

Procedure families: E&M office visits 99212–99215 (99215 = high complexity), Psychotherapy 90832/90834/90837
(90837 = longest session), Therapy 97110/97530, Lab 36415/80053/85025, Imaging 70553/72148/73721,
Procedures 20610/20550.

## data/providers.csv (80 rows)
| Column | Type | Description |
|---|---|---|
| provider_id | string | `PR001`–`PR080` |
| specialty | string | Primary Care, Internal Medicine, Psychiatry, Physical Therapy, Radiology, Orthopedics |
| region | string | Northeast, South, Midwest, West |

## outputs/kpi_summary.csv
Two columns (`kpi`, `value`): total_claims, total_billed_usd, total_paid_usd, flagged_claims, flagged_pct,
estimated_recovery_exposure_usd (paid $ on the union of flagged claims — the amount a payer would put into
review/recovery, types overlap so per-type dollars do not sum to this), duplicate_claims / duplicate_paid_usd
(paid on copies after the first), excessive_units_claims, upcoding_suspect_claims, upcoding_suspect_rate_pct
(% of ALL claims), weekend_flagged_claims, provider_outlier_claims, high_risk_providers,
top_outlier_provider, top_provider_risk_score, top_provider_avg_billed_per_claim,
specialty_peer_avg_billed_per_claim (median avg billed/claim among the top provider's specialty peers).

## outputs/flagged_claims.csv
One row per flagged claim: claim columns plus `flag_types` (semicolon-joined rule names:
duplicate, upcoding_suspect, provider_outlier, excessive_units, weekend_billing) and `primary_flag`
(first rule that fired). A claim can carry several flags.

## outputs/provider_risk_ranking.csv
One row per provider, sorted by risk_score desc: volume (claims, patients), total_billed/paid,
avg_billed_per_claim, avg_billed_per_patient, z_avg_billed_per_claim (WITHIN specialty),
upcoding_rate (high-complexity share of E&M+Psych volume), weekend_share, flagged_claims, flagged_paid,
risk_score and risk_tier.

**risk_score (0–100, capped)** = 12 × max(0, z of avg billed per claim) + 45 × upcoding_rate
+ 25 × weekend_share + 40 × flagged_share of the provider's own claims, + rule-hit points (+12 upcoding rule, +12 outlier rule, +8 weekend rule).
The score is a triage ranking for investigation — it is not evidence of fraud by itself.

## Detection thresholds (analysis.py constants)
Duplicates: exact key match (patient, provider, procedure, date, billed). Excessive units: ≥6 on 97110/97530.
Upcoding: provider rate ≥ max(30%, peer mean + 1.5 SD) with ≥15 family claims. Outlier: within-specialty
z > 2.0 on avg billed per claim or per patient, claims > 1.3× procedure median flagged.
Weekend: ≥35% weekend share with ≥25 claims.
